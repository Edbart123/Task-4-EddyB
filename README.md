# DecodeLabs Week 4 - Data Visualization Project

## Project Overview

This project was completed as part of the DecodeLabs Data Analytics Internship Program.

The objective of this project was to create an interactive Power BI dashboard that transforms raw sales data into meaningful business insights through data visualization and storytelling.

## Tools Used

- Power BI
- Microsoft Excel

## Dashboard Features

- KPI Cards
  - Total Revenue
  - Total Orders
  - Average Order Value
  - Products Sold
- Monthly Sales Trend Analysis
- Revenue by Product
- Orders by Status
- Payment Method Usage
- Revenue by Referral Source

## Key Insights

- Total Revenue exceeded $1.26M
- More than 1,200 orders were processed
- Average Order Value exceeded $1,000
- Over 4,000 products were sold
- Product revenue performance was analyzed across multiple product categories
- Referral sources and payment methods were evaluated to identify customer behavior trends
